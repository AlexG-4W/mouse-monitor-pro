# Lower bounds are the versions this project is actually verified against on the
# development machine (Windows 11, Python 3.11.9 x64). There are deliberately no
# upper bounds: nobody has tested them, and inventing one would forbid versions
# that may well work fine.
#
# This file is ASCII on purpose. pip decodes requirements files using the system
# locale codepage unless a coding declaration is present, so non-ASCII comments
# here break "pip install -r requirements.txt" on any machine whose locale is not
# UTF-8 -- which is most Windows machines. (Found the hard way, in a clean venv.)

# `injected` argument that pynput passes to the on_move / on_click handlers. A
# version that does not pass it leaves the filter permanently inert: no error, no
# warning, just no filtering.
